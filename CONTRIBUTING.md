# Contributing

Thanks for your interest in improving dsh-superagent-sandbox.

## Running the tests

This repository does not have an automated test suite or CI pipeline yet, so
there is no test command to run. Until one is added, verify changes manually:

- Preview the changed Markdown and confirm it renders correctly on GitHub.
- Check that every command and link you add works.
- Note what you checked in your pull request description.

## Proposing a change

1. Open an issue that describes the problem and the change you propose.
2. Fork the repository and branch off `main`.
3. Keep the change focused and avoid unrelated edits.
4. Commit and push, then open a pull request that links the issue and explains
   what changed and how you verified it.
5. Address review comments. A maintainer merges the pull request once it is
   approved.

If you are unsure whether a change fits, open an issue first and discuss it
before writing code.
